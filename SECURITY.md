# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen werden für die jeweils neueste veröffentlichte Version vorgesehen.

| Version | Unterstützt |
| --- | --- |
| 1.0 | Ja |

## Sicherheitsproblem melden

Bitte Sicherheitslücken nicht als öffentliches Issue veröffentlichen. Nutze nach dem Hochladen des Repositorys die GitHub-Funktion **Private vulnerability reporting** unter **Security → Advisories → Report a vulnerability**.

Eine gute Meldung enthält:

- betroffene Version
- technische Beschreibung und mögliche Auswirkungen
- nachvollziehbare Schritte oder einen minimalen Nachweis
- vorgeschlagene Abhilfe, sofern vorhanden

Bitte keine echten Zugangsdaten, personenbezogenen Daten oder fremde lokale Bibliotheksdateien mitsenden.

## Abhängigkeiten und Signierung

Die Anwendung verwendet ausschließlich Apple-Systemframeworks und Swift Package Manager. Automatisch erzeugte öffentliche Builds sind ad-hoc signiert. Für offiziell vertrauenswürdige Downloads sollten Releases zusätzlich mit einer Apple Developer ID signiert und notarisiert werden.
